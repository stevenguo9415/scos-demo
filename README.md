# SCOS 供应链优化系统 Demo

## 项目简介

本项目是中粮太仓 SCOS（Supply Chain Optimization System，供应链优化系统）的前端交互演示，用于展示销售、库存、生产、采购和经营数据的一体化分析，以及从预警发现、方案推演到业务确认和执行回传的供应链决策闭环。

项目采用静态 HTML、CSS 和 JavaScript 构建，内置演示数据，可直接在浏览器中运行，不依赖后端服务。页面中的业务数据、接口状态和推演结果均为演示口径，不代表生产环境的真实数据或正式业务指令。

## 主要功能

- 供应链驾驶舱：展示销售、库存、生产、采购、经营五类核心指标，支持角色视图、指标下钻、实时预警和报告导出。
- 沙盘推演：模拟需求、供应、设备、价格及成本变化，评估库存、交付、产能和利润影响。
- 成品库存优化：覆盖库存总览、健康度分析、补货建议和业务处置。
- 采购优化：覆盖采购计划、供应商与合同约束、审批下发及执行状态回传。
- 原辅包要货计划：展示需求计算、计划编制、异常处理和执行跟踪。
- 精益生产排程：演示订单、产能、物料约束下的生产计划协同。
- 成本核算分析：支持批次谱系、成本归集、多维分析和异常预警。
- 全程追溯协同：串联采购、生产、质量、库存和销售环节的批次信息。

## 目录结构

```text
scos-demo/
├── index.html              # 演示入口与核心页面
├── assets/
│   ├── data/               # 各业务模块演示数据
│   ├── scripts/            # 核心逻辑与模块交互脚本
│   ├── styles/             # 核心样式与模块样式
│   ├── maps/               # 地图数据
│   ├── tools/              # 数据构建和校验工具
│   └── vendor/             # 第三方前端依赖
└── README.md
```

## 本地运行

可直接用浏览器打开 `index.html`。如浏览器限制本地资源加载，建议在项目根目录启动静态文件服务：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。
